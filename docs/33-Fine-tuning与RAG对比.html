Fine-tuning vs RAG

给 AI 变聪明的两条路

🧠
Fine-tuning 微调
"给大脑做手术" — 直接修改模型权重
核心特征
  • 修改模型权重本身
  • 训练后永久改变行为
  • 需要大量标注数据
  • 需要 GPU 算力支撑
优势
  • 回答风格一致
  • 推理延迟低
  • 无需检索设施
劣势
  • 训练成本高
  • 数据过时需重训
  • 可能遗忘能力
VS
📚
RAG 检索增强生成
"给大脑配一本百科全书" — 增强输入信息
核心特征
  • 不修改模型权重
  • 运行时动态增强输入
  • 依赖外部知识库
  • 需要向量数据库
优势
  • 知识实时更新
  • 可追溯来源
  • 部署成本低
劣势
  • 依赖检索质量
  • 增加推理延迟
  • 上下文窗口限制

模型权重修改可视化

Fine-tuning 直接修改神经网络中的权重矩阵。下方每个方块代表一个权重参数，高亮方块 表示被训练修改的权重：

模型通过反向传播算法，根据训练数据调整内部参数，使输出更符合期望结果。

典型数据量

通常需要 1,000 ~ 100,000 条高质量标注数据。数据质量直接决定微调效果。

训练耗时

7B 模型 LoRA 微调约 2~8 小时（单卡 A100）。全量微调需要更多算力和时间。

Embedding 模型

常用 text-embedding-3 或开源的 bge/e5 模型，将文本映射到高维向量空间。

向量数据库

主流选择包括 Milvus / Qdrant / Pinecone，支持毫秒级 ANN 近似最近邻检索。

📚 术语表

Fine-tuning (微调)
在预训练模型基础上，用特定数据继续训练以适应特定任务
RAG (Retrieval-Augmented Generation)
先检索相关文档，再结合检索结果生成回答
Embedding (向量嵌入)
将文本转换为数学向量，语义相近的文本向量也相近
向量数据库 (Vector Database)
专门存储和检索高维向量的数据库
余弦相似度 (Cosine Similarity)
衡量两个向量方向的接近程度，用于语义匹配
权重 (Weights)
神经网络中的可学习参数，决定模型的行为
LoRA (Low-Rank Adaptation)
低秩微调，只训练少量新参数，高效且省资源
Chunk (文档块)
RAG中将长文档切分成的小片段
