Transformer — 当前擂主

统治时间：2017 ("Attention Is All You Need") 至今

统治地位 · 2026 现状

截至 2026 年 3 月，所有顶级大语言模型（GPT-5.4、Claude Opus 4.6、Gemini 3.1、Llama 4、Qwen 3.5...）仍然基于 Transformer 架构。但趋势正在从"纯 Transformer"转向"Transformer 为核心的混合架构"——结合 SSM 层、MoE 稀疏激活等技术。

✓ 高度并行化 ✓ 可扩展性极强 ✓ 生态最成熟 ✓ 推理能力最强 ✓ Flash Attention 3 已成标配 ✓ 1M+ token 上下文已普及 ✗ 理论 O(n²) 注意力复杂度 ✗ 日益走向混合化
2026 关键变化：Flash Attention 3 已成为标准实现，将理论 O(n²) 的实际开销大幅降低。Claude Opus 4.6 和 GPT-5.4 已实现 1M+ token 上下文窗口。Transformer 并未被"替代"，而是通过吸收 SSM、MoE 等技术不断进化——最大的挑战者们正在成为 Transformer 的组成部分。
🐍

Mamba — 选择性状态空间模型

👤 Albert Gu, Tri Dao · Mamba 1 (2023) · Mamba 2 (2024)

核心创新

选择性状态空间模型（Selective SSM）— 用递推替代注意力机制。不再计算所有 token 之间的关系，而是维护一个"隐状态"，每个新 token 动态更新隐状态。

训练 O(n)
推理 O(n)
原理简述：像 RNN 一样维护隐状态，但使用"选择性扫描"算法实现并行训练。关键在于"选择性"——根据输入内容动态调整状态转移矩阵，让模型选择性地记住或遗忘信息。

2026 最新进展

  • Mamba 2 (2024) — 提出 SSD (State Space Duality) 框架，揭示 SSM 与注意力机制的数学对偶关系。硬件利用率大幅提升，训练速度比 Mamba 1 快 2-8 倍。
  • Jamba (AI21 Labs) — 混合 Mamba + Transformer 架构，256K 上下文窗口，已投入生产环境。这是混合架构路线的标杆之作。
  • 混合模型成趋势 — 多个团队采用"Mamba 层 + Attention 层"交替的混合架构，用 SSM 处理长序列、用 Attention 做精确推理。
  • 在长序列任务（如长文档检索、基因序列分析）上表现突出，但纯 Mamba 在复杂推理任务上仍不及 Transformer。
✓ O(n) 线性复杂度 ✓ 长序列性能优秀 ✓ 显存占用大幅降低 ✓ Mamba 2 硬件效率大幅提升 ✓ Jamba 等混合模型已生产就绪 ✗ 纯 SSM 推理能力仍弱于 Transformer ✗ 独立生态仍较小 ◐ 最佳路径：与 Transformer 混合使用
🦅

RWKV — RNN 与 Transformer 的混合体

👤 Bo Peng · RWKV-6 Eagle (2024) · RWKV-7 Goose (2025)

核心创新

"用 Transformer 的方式训练 RNN" — 训练时像 Transformer 一样高度并行，推理时像 RNN 一样递推，实现 O(1) 常数级推理。这是真正的恒定内存推理，非常适合资源受限的部署场景。

训练 O(n)
推理 O(1)
原理简述：RWKV = Receptance Weighted Key Value。使用线性注意力的变体实现并行训练，同时保留 RNN 的递推特性。推理时每步只需更新固定大小的状态向量，与上下文长度无关。

2026 最新进展

  • RWKV-6 "Eagle" — 多语言能力显著增强，长上下文表现改善。社区已训练多个语言的 Eagle 变体。
  • RWKV-7 "Goose" — 进一步改进架构设计，在多个基准测试上缩小了与 Transformer 的差距。
  • 边缘部署王者 — 由于真正 O(1) 的逐 token 推理内存，RWKV 在边缘设备、嵌入式系统、低资源部署场景中有独特优势。
  • 社区持续壮大，但与 Transformer 生态相比仍属小众。主要在中英文社区活跃。
✓ 训练 O(n)，推理 O(1) ✓ 完全开源，社区活跃 ✓ 推理时显存恒定 ✓ 边缘部署最佳选择 ✓ RWKV-7 持续缩小性能差距 ✗ 大规模模型验证仍不足 ✗ 复杂推理任务仍有差距 ◐ 社区增长中但仍属小众
🧠

MoE — 混合专家模型 ✓ 已成主流

📌 DeepSeek V3 (671B/37B) · Mistral Large 3 · Llama 4 · Qwen 3.5

核心创新

稀疏激活 — 模型有多个"专家"子网络，但每次只激活其中少数几个。以 DeepSeek V3 为例：总参数 671B，但每次推理只激活 37B 的计算量。用少量计算获得超大模型的效果。

训练 O(n²) 稀疏
推理 O(n²/k)
2026 重要更新：MoE 已从"挑战者"变为主流标准技术。它不再是 Transformer 的替代品，而是 Transformer 架构内部的标准组件。几乎所有新一代旗舰模型都采用 MoE：DeepSeek V3 (671B/37B active)、Mistral Large 3 (675B/41B active)、Llama 4 (全系 MoE)、Qwen 3.5 (MoE)。训练稳定性问题已基本解决，专家路由技术（如 DeepSeek 的 Multi-Head Latent Attention）持续创新。

2026 最新进展

  • DeepSeek V3 — 671B 总参数 / 37B 活跃参数，刷新开源模型性能记录。创新的 Multi-Head Latent Attention 和改进的专家路由。
  • Llama 4 全系 MoE — Meta 全面拥抱 MoE 架构，标志着 MoE 从实验走向标准配置。
  • 训练稳定性突破 — 专家坍缩和负载均衡问题已通过 auxiliary loss、router z-loss 等技术大幅缓解。
  • MoE 不再是"挑战者" — 它已成为 Transformer 架构内部的标准增强技术，就像 LayerNorm 和 RoPE 一样普及。
✓ 少量计算，超大模型效果 ✓ 已成为行业标准架构 ✓ 推理计算量大幅降低 ✓ DeepSeek/Llama/Mistral/Qwen 全面采用 ✓ 训练稳定性问题已基本解决 ✗ 显存仍需装载全部参数 ✗ 通信开销在分布式训练中仍显著 ◐ 已从"挑战者"毕业为"标配"

线性注意力变体 — 优化而非替代

📌 Flash Attention 3 · Performer · Linear Attention

核心创新

两条路线：(1) 用核函数近似 softmax attention，将复杂度从 O(n²) 降到 O(n)；(2) 通过 IO 感知优化（如 Flash Attention），不改架构但大幅提速。Flash Attention 3 的成功使得 Transformer 在实践中的 O(n²) 成本大幅降低，反而巩固了 Transformer 的统治地位。

Flash Attention 3
Tri Dao 团队最新版本，针对 Hopper 架构 GPU (H100/H200) 深度优化。异步化 + warp 调度，已成为 2026 年所有主流模型的标配，是 1M+ token 上下文的关键支撑。
Performer / Linear Attn
用核函数近似 softmax 实现 O(n) 复杂度。由于 Flash Attention 的成功和混合 SSM 架构的兴起，纯线性注意力路线热度有所下降。
Ring Attention
将长序列切块分发到多个设备上并行计算注意力，实现近乎无限上下文长度。是 1M+ token 模型的另一关键技术。
✓ Flash Attention 3 已成为行业标配 ✓ 支撑 1M+ token 上下文成为现实 ✓ 可与现有架构完全兼容 ✗ 近似方法有精度损失 ✗ 纯线性注意力路线热度下降 ◐ Flash Attention 反而巩固了 Transformer

混合架构 — 2025-2026 真正的新趋势

📌 Jamba · StripedHyena · Mamba+Attention 混合 · SSM+MoE

核心理念

不再追问"谁能替代 Transformer"，而是把各架构的优势组合起来。典型做法：用 Attention 层做需要精确推理的部分，用 SSM/Mamba 层高效处理长序列，用 MoE 在不增加推理成本的前提下扩大模型容量。

训练 亚 O(n²)
推理 优于纯 Transformer
核心洞察：2025-2026 年的实践表明，没有单一架构能在所有维度上最优。Attention 擅长推理和精确检索，SSM 擅长长序列和低延迟，MoE 擅长高效扩容。混合架构取各家之长：交替使用不同类型的层，在同一个模型中融合多种机制。Jamba (AI21) 是这一路线的先行者，使用交替的 Mamba 层和 Attention 层 + MoE，在 256K 上下文下表现优异。

代表模型

  • Jamba (AI21 Labs) — Mamba + Transformer + MoE 三合一，256K 上下文，吞吐量比同等 Transformer 高 3 倍。已投入商业生产。
  • StripedHyena — Together AI 提出的混合架构，交替 Hyena (长卷积) 层和 Attention 层。
  • Zamba / Zamba2 — Zyphra 的混合 SSM-Transformer 模型，在小模型规模上表现优异。
  • 多家实验室在探索 — Google、Meta、Anthropic 等均在研究将 SSM 层融入 Transformer 的可能性。
✓ 兼具 Attention 的推理力和 SSM 的效率 ✓ 长序列 + 强推理两不误 ✓ Jamba 已验证生产可行性 ✓ 可灵活调整层的配比 ✗ 架构设计空间巨大，最优配比未定 ✗ 训练和调优复杂度更高 ◐ 可能是架构之争的最终答案
