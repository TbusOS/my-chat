术语表

Token
词元 / 标记
模型处理文本的最小单位。中文通常一个字或词为一个 Token。
Embedding
词向量 / 嵌入
把词编号映射到高维空间的一个向量，让相似词的位置更近。
Self-Attention
自注意力机制
让句中每个词关注所有词，根据相关性加权融合信息。Transformer 的核心。
Query (Q)
查询向量
代表「我在找什么」。每个词生成 Q，去匹配其他词的 K。
Key (K)
键向量
代表「我是什么」。被其他词的 Q 来匹配和查询。
Value (V)
值向量
代表「我的内容」。匹配成功后，按权重传递的实际信息。
Dot Product
点积
两个向量相似度的数学度量。方向越同向，值越大。
Softmax
归一化指数函数
把一组分数转成概率分布（加和为 1），让权重更集中。
Multi-Head Attention
多头注意力
同时用多组 Q/K/V 从不同角度观察句子，再拼接结果。
Positional Encoding
位置编码
注意力本身没有顺序感，需要额外给每个词加入位置信息。
Feed Forward Network
前馈网络
注意力之后的全连接层，对每个词独立做非线性变换。
Residual Connection
残差连接
将输入直接加到输出上的「捷径」，帮助深层网络稳定训练。
