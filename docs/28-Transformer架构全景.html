术语表 Glossary
Transformer
一种神经网络架构，2017年由Google提出，是当前几乎所有大模型的基础
Encoder（编码器）
将输入文本转换为数学表示（向量）的模块
Decoder（解码器）
将向量转换回文本输出的模块
Embedding（嵌入）
将文字转换成数字向量的过程
Positional Encoding（位置编码）
告诉模型每个词在句子中的位置
Multi-Head Attention（多头注意力）
多个"视角"同时关注输入的不同方面
Q/K/V (Query/Key/Value)
注意力机制的三个核心矩阵：查询、键、值
Feed Forward Network (FFN)
前馈神经网络，对每个位置独立做非线性变换
Residual Connection（残差连接）
跳过某些层直接传递信息，防止信息丢失
Layer Normalization（层归一化）
标准化数据使训练更稳定
Softmax
将数字转换为概率分布的函数
Masked Attention（掩码注意力）
防止解码器"偷看"未来的词
