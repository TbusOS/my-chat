📚 术语表

预训练 (Pre-training)
在海量文本上学习语言模式的第一阶段
前向传播 (Forward Pass)
数据从输入到输出逐层计算的过程
反向传播 (Backpropagation)
从损失函数反向计算每个参数的梯度
Loss (损失函数)
衡量模型预测与正确答案差距的数学函数
梯度下降 (Gradient Descent)
沿梯度方向调整参数以减小Loss的优化算法
SFT (Supervised Fine-Tuning, 监督微调)
用人工标注的高质量问答数据训练模型"说人话"
RLHF (人类反馈强化学习)
用人类偏好排序训练奖励模型，再用PPO算法对齐
PPO (Proximal Policy Optimization)
强化学习算法，用于RLHF的最后一步
Epoch
模型将所有训练数据完整看一遍的次数
Batch Size (批次大小)
每次参数更新使用的样本数量
Learning Rate (学习率)
每次参数更新的步长，太大会震荡，太小会很慢
