💠 光子矩阵乘法阵列
Photonic MVM Array — Mach-Zehnder Interferometer Matrix
💡 为什么用光做矩阵乘法？
  • 矩阵乘法占 AI 计算 90%+ 的算力需求
  • 光子在 MZI 阵列中完成干涉叠加 = 矩阵乘法，光速运算（~3×10⁸ m/s）
  • 光子没有电荷，运算不产热，能耗降低 100-1000×
  • 天然并行：多波长复用 = 同时算多组矩阵乘法

⚡ 电子非线性激活单元
Electronic Nonlinear Activation Unit — CMOS Activation Circuits
💡 为什么不全用光？
  • 光擅长线性运算（叠加、干涉），但非线性运算极其困难
  • 神经网络必须有非线性（ReLU、GELU、Sigmoid），否则多层等价于一层
  • 光做非线性需要极高光强（非线性光学效应），能效极差
  • 最优解：光做线性 + 电做非线性 = 光电混合

💾 存算一体 SRAM 阵列
Computing-in-Memory SRAM — Analog MAC in Memory Cells
💡 解决什么问题？
  • 传统架构中，数据在计算单元和存储之间反复搬运（"内存墙"问题）
  • 数据搬运消耗的能量是计算本身的 100-1000 倍
  • CIM-SRAM：权重直接存在 SRAM 中，乘加运算就地完成
  • 特别适合推理（权重固定不变），与光子阵列互补配合

🔀 异步脉冲路由网络
Asynchronous Spike Routing Network — Event-Driven Communication
💡 仿生物神经网络通信
  • 传统芯片用全局时钟同步所有操作 — 大量无效等待
  • 生物大脑是事件驱动的：有数据才传输，无数据则静默
  • 异步脉冲路由：减少 80%+ 的无效通信
  • 配合稀疏注意力：只有被选中的路径才激活，像互联网数据包路由

📚 术语表

PENP（Photonic-Electronic Neural Processor）
本动画设计的理想芯片名称：光电混合神经处理器
MZI（Mach-Zehnder Interferometer, 马赫-曾德尔干涉仪）
光学元件，利用光的干涉实现矩阵运算
MVM（Matrix-Vector Multiplication, 矩阵向量乘法）
AI最核心的运算
光电转换
光信号和电信号之间的相互转换
CMOS
互补金属氧化物半导体，现代芯片的主流制造工艺
ReLU / GELU（激活函数）
引入非线性的数学函数，是神经网络能学习复杂模式的关键
CIM（Computing in Memory, 存算一体）
在存储器内部直接完成计算
SRAM（Static RAM）
静态随机存取存储器，速度极快，用于芯片内部缓存
异步（Asynchronous）
无全局时钟，各模块按需独立工作
脉冲路由（Spike Routing）
仿神经元的按需通信方式，仅在有数据时传输
PFLOPS（PetaFLOPS）
每秒千万亿次浮点运算，衡量超级计算能力
TFLOPS/W
每瓦功耗的万亿次浮点运算，衡量能效比
