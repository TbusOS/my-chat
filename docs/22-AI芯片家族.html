AI 芯片术语表

GPU (Graphics Processing Unit)
图形处理器。拥有数千个并行核心，擅长大规模矩阵运算，是当前 AI 训练和推理的主力芯片。代表厂商：NVIDIA、AMD。
TPU (Tensor Processing Unit)
张量处理器。Google 自研的 AI 专用芯片，针对矩阵乘法和 AI 工作负载深度优化，用于训练和运行 Gemini 等模型。
NPU (Neural Processing Unit)
神经网络处理器。集成在手机/笔记本 SoC 中的低功耗 AI 加速器，用于端侧推理（如语音识别、AI 拍照）。代表：Apple Neural Engine、高通 Hexagon。
LPU (Language Processing Unit)
语言处理器。Groq 公司设计的推理专用芯片，采用确定性流式架构，提供极低延迟的 LLM 推理。2025 年底被 NVIDIA 收购。
HBM (High Bandwidth Memory)
高带宽内存。通过 3D 堆叠实现超高带宽的内存技术。HBM3 (H100) → HBM3e (B200/B300) → HBM4 (Rubin)，每代带宽和容量大幅提升。
FLOPS / PFLOPS / EFLOPS
每秒浮点运算次数。PFLOPS = 10^15 FLOPS (千万亿次)，EFLOPS = 10^18 FLOPS (百亿亿次)。衡量芯片算力的核心指标。
FP4 / FP8 / FP16 / FP32
浮点精度格式。FP32 (全精度) 用于科学计算；FP16/BF16 (半精度) 用于训练；FP8 用于推理；FP4 (四位) 是最新的极低精度格式，算力最高但精度最低。
NVLink
NVIDIA 的高速 GPU 互联技术。NVLink 5 (Blackwell) 提供 1.8TB/s 带宽，NVLink 6 (Rubin) 达到 260TB/s 聚合带宽，远超 PCIe。
PCIe (Peripheral Component Interconnect Express)
通用高速总线标准。PCIe 5.0 单向带宽 ~64GB/s (x16)，是连接 CPU 和 GPU 的标准接口，但带宽远低于 NVLink。
制程 (Process Node)
芯片制造工艺节点。如 4nm (Blackwell)、3nm (Rubin / AMD CDNA 4)。制程越小，同面积晶体管越多，性能和能效越好。
TDP (Thermal Design Power)
热设计功耗。芯片满负载运行时的最大散热需求，单位瓦特 (W)。例如 B200 为 1000W，B300 为 1400W，Rubin 预计更高，均需液冷散热。
MoE 加速 (Mixture of Experts)
混合专家模型的硬件加速。MoE 模型（如 GPT-4）只激活部分参数，新一代芯片如 Rubin 针对 MoE 的稀疏计算模式做了专门优化，训练 GPU 需求降低 4 倍。
