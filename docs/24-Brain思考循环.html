Agentic Loop：Brain 的核心工作方式
Brain 不是调用一次 LLM 就结束，而是循环调用 LLM → 执行工具 → 再调用 LLM... 直到任务完成。每个 Brain 运行在独立的 Session Lane 中（并发=1，single-writer 模式）
