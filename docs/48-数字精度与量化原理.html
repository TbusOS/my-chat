量化是怎么做的
量化就是把"连续的高精度数字"映射到"有限的低精度整数"上。以下是具体步骤。
1收集权重分布
模型的权重通常呈钟形分布，大部分数值集中在 0 附近。
2确定缩放因子
找到最大值和最小值，计算 Scale = (max - min) / (2^bits - 1)，划出量化网格。
3映射到整数
每个浮点权重"跳"到最近的网格线上（取整），落在网格线之间的数字会损失精度。
4反量化（恢复近似值）
推理时，整数 x Scale + Zero_point = 近似浮点数。但已经是"阶梯"而非平滑曲线。

对称量化 (Symmetric)

零点固定为 0，正负范围相同。
计算简单，但如果权重分布不对称，会浪费一部分范围。

非对称量化 (Asymmetric)

零点可以偏移，更好地利用量化范围。
适合分布不均匀的权重，精度更高但计算稍复杂。

量化方法对比
不同的量化方法在精度、速度和成本之间取舍。选择取决于你的部署场景。

PTQ

Post-Training Quantization 训练后量化
  • 不需要重新训练，直接转换权重
  • 最快速的量化方式
  • 精度损失相对较大
  • 代表：llama.cpp GGUF 量化

GPTQ

GPU-Optimized PTQ
  • 逐层量化，用校准数据优化
  • 需要 GPU + 校准数据集
  • 精度优于朴素 PTQ
  • 4-bit 量化仍保持不错质量

AWQ

Activation-Aware Weight Quantization
  • 识别"重要"权重，给予更高精度
  • 1% 的权重影响 50%+ 性能！
  • 保护关键权重 = 更好的量化质量
  • 不是所有权重同等重要

QAT

Quantization-Aware Training 量化感知训练
  • 训练时模拟量化误差
  • 模型"学会"在低精度下工作
  • 最好的精度保持
  • 需要重新训练（成本高）

GGUF

llama.cpp 专用格式
  • 支持混合量化：重要层高精度
  • Q4_K_M, Q5_K_M, Q8_0 等变体
  • 最适合本地 / CPU 推理
  • 社区广泛使用，生态最好
有损 vs 无损
精度转换是否丢失信息？取决于源格式和目标格式的关系。

无损 (Lossless)

  • FP32 -> FP16：若数值在 FP16 范围内且精度足够，可以无损
  • BF16 -> FP32：几乎无损（指数范围相同，精度只会增加）
  • 类比：PNG 图片压缩 — 文件变小但像素完全相同

有损 (Lossy)

  • FP32 -> INT8：一定有损（连续 -> 离散化）
  • FP32 -> INT4：损失更大（仅 16 个离散值）
  • 类比：JPEG 图片压缩 — 文件大幅变小但有模糊

混合精度 (Mixed Precision)

关键层用 FP16/BF16，普通层用 INT8/INT4 — "把预算花在刀刃上"

NVIDIA Tensor Core 天生支持混合精度计算。训练时 FP32 做累加、BF16 做乘法，既快又稳。推理时关键的注意力层保留高精度，FFN 层大胆量化。

术语表

浮点数 (Floating Point)
用科学计数法表示的小数。如 3.14 = 1.57 x 2^1。"浮动"的小数点让它能表示很大或很小的数。
定点数/整数 (Integer)
没有小数点的整数，如 -128 到 127。计算快但不能表示小数。
符号位 (Sign Bit)
1 位，决定正数(0)还是负数(1)。所有格式的第一位。
指数 (Exponent)
决定数字的范围/大小。指数位越多，能表示的数字范围越大。
尾数 (Mantissa/Fraction)
决定数字的精度/细节。尾数位越多，数字越精确。
FP32
32 位浮点，标准训练精度。1 位符号 + 8 位指数 + 23 位尾数。
FP16
16 位浮点，推理常用。1 位符号 + 5 位指数 + 10 位尾数。
BF16 (Brain Float 16)
Google 提出。保留 FP32 的指数范围(8位)但减少精度位(7位)。训练更稳定。
FP8
8 位浮点。NVIDIA Hopper/Blackwell 架构原生支持。1+4+3 布局。
INT8 / INT4
8 位/4 位整数。量化推理专用。INT8 有 256 个值，INT4 仅 16 个值。
量化 (Quantization)
将高精度数字映射到低精度表示的过程。好比把高清照片压缩成缩略图。
反量化 (Dequantization)
将量化后的整数还原为近似浮点数。integer x scale + zero_point = ~float。
校准 (Calibration)
用样本数据确定量化的最佳参数（scale 和 zero point），让量化误差最小。
混合精度 (Mixed Precision)
不同层使用不同精度。关键层高精度，普通层低精度。"把钱花在刀刃上"。
