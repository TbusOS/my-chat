❓ AI 术语表 Glossary

API Application Programming Interface
应用程序编程接口，允许不同软件之间相互通信的标准协议。例如 OpenAI API 让开发者调用 GPT 模型。
SDK Software Development Kit
软件开发工具包，提供库、文档和示例代码，帮助开发者快速集成某项服务或功能。
Framework 框架
预构建的代码骨架和工具集，如 PyTorch（训练框架）、LangChain（编排框架），帮助开发者专注业务逻辑。
推理 vs 训练 Inference vs Training
训练 (Training)：用海量数据教会模型学习模式，需要大量 GPU 和数周时间。
推理 (Inference)：用训练好的模型处理新输入并产出结果，是用户实际使用时的过程。
向量数据库 Vector Database
专门存储和检索高维向量的数据库。文本/图片被转为数学向量后存入，通过"相似度搜索"找到语义最相关的内容。
Agent 智能体
能自主规划、决策和执行任务的 AI 系统。与普通聊天不同，Agent 可以调用工具、读写文件、访问网络，完成复杂多步骤任务。
MCP Model Context Protocol
模型上下文协议，Anthropic 提出的开放标准，让 AI 模型以统一方式连接外部数据源和工具，类似 AI 世界的"USB 接口"。
RAG Retrieval-Augmented Generation
检索增强生成，先从知识库检索相关信息，再结合检索结果让 LLM 生成回答，有效减少"幻觉"并提供最新知识。
Fine-tuning 微调
在预训练模型基础上，用特定领域数据进一步训练，使模型适应特定任务（如医疗问答、法律分析），成本远低于从零训练。
Open Source vs Closed Source 开源 vs 闭源
开源：模型权重和代码公开（如 Llama 4、DeepSeek R1），可自由下载部署和修改。
闭源：仅通过 API 提供服务（如 GPT-5.4、Claude），模型细节不公开，由厂商控制访问。
