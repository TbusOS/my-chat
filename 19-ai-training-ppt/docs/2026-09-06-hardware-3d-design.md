## 1. 目标 / 非目标

## 2. 为什么之前"假"（阶段 0 得出的结论，按重要性排）

1. **光比** —— 柔光箱 16.0 把 4% 反射率的黑塑封打成灰；降到 6.2 材质数值一个没改就黑下来了。
2. **美术方向** —— 深蓝虚空 + 霓虹描边一定读成"动画"；中性灰棚拍 + 真实元件配色 + 零自发光才读成"照片"。
3. **抗锯齿的重建核** —— ±0.5px 均匀抖动累积 = 1px 盒式模糊，全画面必软；高斯 σ0.32 才锐。
4. **对焦面方向** —— 焦平面垂直视线时斜俯视只有一条带清晰；焦平面贴板面（移轴剪切）整板全锐。
5. 材质单一 / 无接触阴影 / 无真圆角 / 无表面细节 / 元件太少 —— 每条都要，但排在前四条之后。

## 3. 引擎（`hw3d` 内核，阶段 0 已实现并验收）

渲染链：阴影深度 → G-buffer(MRT: albedo+metallic / normal+roughness / depth) → SSAO(前 6 帧双边模糊，之后靠累积) → IBL 光照(GGX + split-sum，阴影作方向遮挡) → 累积平均(RGBA32F) → 泛光 → ACES + 轻锐化 + 颗粒 + 暗角。

- 环境光：开机程序化烘棚拍 cubemap（3 块矩形柔光箱 + 背景纸渐变）→ 6 级 GGX 预过滤 + 32² 辐照度 + 128² BRDF LUT。零外部文件。
- 累积采样：相机静止后每帧抖动 → 亚像素(高斯) / 光圈盘(景深) / 柔光箱面积(软阴影) / AO 核旋转，200 帧收敛。
- 薄透镜 = 平移 + 剪切（Haeberli & Akeley 1990），焦平面任意朝向 → `focus:'point'|'plane'`。
- 几何：真圆角盒（6 面 + 12 边 + 8 角）+ 圆柱；按元件类型建原型，实例化。
- 表面：丝印图集(Canvas 2D 现画，1024/格，fwidth 阈值重建)；PCB 走线/阻焊/位号框；die 版图；微观粗糙度/法线扰动。
- 材质表见 `MAT`（目测调的，不是实测）。
- 可观测：`window.__hw3d.{caps,spp,converged,errs,glError,shot,setSpp}`；实例缓冲溢出断言。

## 5. 叠加层（数据流）设计

- 写实底层照常累积；叠加层**每个显示帧单独画**到自己的 HDR 缓冲（深度附件复用 G-buffer 深度，只测不写，用最后一次采样的 VP），再与累积结果相加后进泛光/后期。原因：流动物体进累积会被平均成拖影。
- 元素：包(实例化小圆角块沿折线运动) · 通道高亮(实例化盒 + 逐实例相位) · 路径丝带(低 alpha) · 扫描线。
- 颜色纪律：最多 3 个强调色（命令=琥珀，数据=青，像素=洋红），几何本体绝不发光。
- 半透明（LCD 层、玻璃）走同一前向通道，alpha 混合。
