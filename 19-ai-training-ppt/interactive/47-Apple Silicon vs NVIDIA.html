Apple Silicon VS NVIDIA

统一内存 vs 离散显存的 AI 之争 | 2026.03
Apple Silicon — 统一内存架构 (UMA)
零拷贝 — 数据原地不动，计算来找数据 LPDDR5X | 最高 512GB (M3 Ultra) | 120-819 GB/s
VS
NVIDIA — 离散 GPU 架构
数据搬运 — 先把数据搬到GPU，才能开始计算 HBM3e | 最高 192GB (B200) | 3,350-8,000 GB/s
⚡ 核心洞察：Apple 的带宽低但零拷贝；NVIDIA 带宽高但需要搬运数据。当模型放不进 GPU 显存时，Apple 反而更快 — 因为 NVIDIA 需要在 CPU 内存和 GPU 显存之间反复搬运数据，PCIe 的带宽瓶颈会严重拖慢速度。

术语表 (Glossary)

UMA (Unified Memory Architecture)
统一内存架构 — CPU / GPU / NPU 共享同一块内存，无需数据拷贝。
HBM (High Bandwidth Memory)
高带宽内存 — GPU 专用堆叠式高速显存，带宽远超传统 DDR。
VRAM (Video RAM)
显存 — GPU 专属内存，与系统内存物理分离。
PCIe
连接 CPU 和 GPU 的总线，带宽远低于 GPU 内部带宽和 NVLink。
NVLink
NVIDIA GPU 间直连高速通道，带宽远超 PCIe。
TOPS (Tera Operations Per Second)
每秒万亿次运算 — 衡量 AI 加速器算力的核心指标。
Neural Engine
Apple 专用 AI 加速器，集成在 SoC 中，专攻矩阵运算和推理。
Tensor Core
NVIDIA 专用矩阵运算核心，每个 GPU 包含数千个，大幅加速 AI 训练和推理。
Metal
Apple 的 GPU 编程框架，类似 CUDA 但仅限 Apple 平台。
CUDA
NVIDIA 的 GPU 编程框架，AI 领域的事实标准。~17 年历史。
MLX
Apple 的机器学习框架，针对 Apple Silicon 优化。2025 新增 CUDA 后端。
tok/s (tokens per second)
大模型每秒生成的 token 数 — 衡量推理速度的核心指标。
Quantization (量化)
降低模型精度（如 FP16→INT4）以减小体积和提高速度，通常精度损失很小。
Offloading (卸载)
模型超出显存时，将部分权重放到 CPU 内存。速度大幅下降（受 PCIe 带宽限制）。
