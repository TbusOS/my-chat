🧱 显存墙问题
GPT-4 参数量约 1.8 万亿，FP16 需要 ~3.6 TB 显存。单张 H100 只有 80 GB HBM3。 一个模型需要 45+ 张 H100 才能放下参数。这就是为什么需要模型并行、量化压缩等技术。

📖 术语表 Glossary
GPUGraphics Processing Unit, 图形处理器
拥有数千个计算核心的并行处理器，AI计算的主力
CPUCentral Processing Unit, 中央处理器
拥有少量强大核心的通用处理器，擅长复杂逻辑
CUDA Core
NVIDIA GPU的通用计算核心，执行浮点乘加运算
Tensor Core
NVIDIA GPU的专用矩阵计算核心，一次完成4×4矩阵乘法，速度是CUDA Core的8-16倍
Thread线程
GPU中最小的执行单元，一个线程执行一次计算
Warp线程束
32个线程组成的执行组，同步执行相同指令
Block线程块
多个Warp组成的协作组，可共享内存
Grid网格
多个Block组成的计算任务全集
SMStreaming Multiprocessor, 流式多处理器
GPU的基本计算模块，包含多个CUDA/Tensor Core
SIMTSingle Instruction Multiple Threads
单指令多线程，所有线程执行相同指令但处理不同数据
HBMHigh Bandwidth Memory, 高带宽存储器
GPU专用显存，堆叠式封装，带宽极高
FLOPSFloating Point Operations Per Second
每秒浮点运算次数，衡量算力的单位
显存带宽Memory Bandwidth
数据在显存和计算核心之间的传输速度
FMAFused Multiply-Add
融合乘加运算，a×b+c一步完成
