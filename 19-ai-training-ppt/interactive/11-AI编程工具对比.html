术语解释 Glossary

IDE Integrated Development Environment
集成开发环境，写代码用的软件（如 VS Code、Cursor）
Agent / Agentic
智能体 / 自主执行模式
AI 能自主规划和执行多步任务，而不只是回答问题
Context Window
上下文窗口 — 模型一次能理解的代码量上限
例如 1M tokens 约等于一次读懂 ~75 万行代码
Copilot
副驾驶 — 辅助编程的 AI 助手
你是驾驶员，AI 是副驾帮你导航和操作
MCP Model Context Protocol
模型上下文协议 — AI 工具的标准接口
让 AI 能统一访问数据库、API、文件系统等外部资源
RAG Retrieval-Augmented Generation
检索增强生成 — 从代码库检索相关代码辅助生成
先搜索找到相关代码片段，再让 AI 基于这些片段生成答案
LSP Language Server Protocol
语言服务协议 — 代码智能提示的标准协议
让编辑器能理解代码结构，提供跳转定义、自动补全等功能
Latency
延迟 — AI 响应的等待时间
从你发送请求到 AI 开始回复的时间间隔
