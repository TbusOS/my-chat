GPU / 显卡
AI 的"大脑" — 最重要!
  • VRAM (显存) = 能装多大的模型
  • CUDA / Tensor Cores = 计算有多快
  • 显存带宽 = 数据喂给计算核心的速度
关键指标优先级: VRAM容量 > 显存带宽 > 算力(TFLOPS)

CPU / 处理器
调度员 — 协调数据流
  • 不直接做 AI 计算，但负责数据预处理、调度 GPU
  • 核心数影响数据加载 Pipeline 效率
  • 推理场景: 高主频优先 (单线程性能)
  • 训练场景: 多核优先 (数据并行加载)
  • llama.cpp CPU 推理: 核心数越多越快
推理选高频，训练选多核
🗄
RAM / 内存
临时仓库 — 数据中转站
  • 数据集加载、模型加载前的中转站
  • CPU 推理时: RAM = "显存"（模型放在内存里）
  • Apple Silicon 统一内存: RAM 就是 VRAM
RAM >= 2x GPU VRAM（至少等于模型大小）
💾
Storage / 存储
模型仓库 — 持久化存储
  • NVMe SSD: 70B 模型 ~40GB，NVMe 8秒 vs SATA 30秒
  • 每个模型 10-100GB，加上数据集，建议 2TB 起
  • 训练时: 数据集 IO 是瓶颈，必须 NVMe
NVMe Gen4 起步，容量 2TB+
🌐
Network / 网络
多机必需 — 单机可忽略
  • 单机不需要特殊网络配置
  • 多机分布式: InfiniBand(最佳) > RoCE > 万兆以太网
  • 带宽决定 GPU 间梯度同步速度
  • InfiniBand 400Gb/s vs 以太网 100Gb/s
单机忽略，多机必须 InfiniBand

💰 8 个省钱秘籍

聪明花钱，不多花冤枉钱。

1

二手 GPU

A100 40GB 二手约 3万（新品 10万+），性价比极高。矿卡 RTX 3090 有风险，检查显存是否正常。

2

云端按需

不需要 24/7 跑的话，Lambda / Vast.ai / RunPod 按小时租比买划算。偶尔微调用云端，日常推理用本地。

3

量化是王道

70B Q4 约 40GB，质量下降仅约 5%，但硬件需求降 75%。Q5 性价比更好。

4

LoRA 微调

不需要全量训练，LoRA 只需 1张卡 就能微调 70B 模型。QLoRA 更省显存。

5

Apple Silicon 隐藏优势

M4 Max 2.5万 = 128GB 统一内存，跑 70B 模型不需要 10万+ 的 GPU 集群。速度慢但能跑。

6

组合方案

Mac 本地开发 + 云端训练 = 最佳性价比。本地跑 7B 调试，上云微调 70B。

7

开源优先

DeepSeek R1 / Qwen3.5 免费下载，不用花钱买 API。本地部署零边际成本。

8

共享 GPU

团队合买一台多卡服务器，比每人一张卡划算。用 vLLM 做推理服务共享。

术语表 Glossary

VRAM (Video RAM, 显存)
GPU 专属内存，决定能装多大的模型。24GB VRAM 能装约 13B FP16 模型。
统一内存 (Unified Memory)
Apple Silicon 的 CPU/GPU 共享内存，M4 Max 最高 128GB，全部可用于模型推理。
HBM (High Bandwidth Memory)
高端 GPU 使用的高带宽堆叠显存，如 H100 使用 HBM3，带宽 3,350 GB/s。
TFLOPS
每秒万亿次浮点运算，衡量 GPU 算力。RTX 4090 FP16 约 83 TFLOPS。
NVLink
NVIDIA 多 GPU 直连高速通道，允许 GPU 间共享显存，带宽可达 900 GB/s。
InfiniBand
多机 GPU 集群的高速网络，400Gb/s，是分布式训练的关键基础设施。
量化 (Quantization)
降低模型精度以减小体积。FP16 → Q4 可减小 75% 体积，质量下降约 5%。
Q4 / Q5 / Q8
GGUF 格式的不同量化级别。Q4=4bit 最小，Q8=8bit 最接近原始质量。
LoRA (Low-Rank Adaptation)
低秩微调，用少量参数高效微调大模型，显存需求仅为全量训练的 1/10。
tok/s (tokens per second)
推理速度指标，人类阅读速度约 5-8 tok/s，>20 tok/s 体验流畅。
batch size
同时处理的样本数，影响训练效率和显存占用。越大训练越快但越吃显存。
NVMe SSD
高速固态硬盘，读取速度 5-7 GB/s（Gen4），影响模型加载速度。
