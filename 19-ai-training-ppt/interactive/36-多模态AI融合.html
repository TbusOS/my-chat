场景1：看图说话（图像 + 文本）

将图片通过 ViT 编码为视觉 token，和文本 prompt 的 token 拼接后送入大语言模型。模型在统一的 token 空间中理解图片内容，生成自然语言描述。GPT-4V、Gemini 都使用这一架构。

CLIP
图文对齐模型
OpenAI 的 CLIP 模型同时训练一个图像编码器和一个文本编码器，让匹配的图文对在向量空间中距离最近。训练了 4 亿图文对，实现了零样本图像分类。
Contrastive Learning
对比学习
核心思想：相关的图文对应该靠近，不相关的应该远离。通过 InfoNCE 损失函数，在一个 batch 中将正对拉近、负对推远，学出统一的表征空间。
Unified Tokens
统一 Token 空间
将图像、音频、视频都"翻译"成 token 序列，和文本 token 共享同一个 Transformer。对模型来说，一切都是 token 流 — 图片是 token，声音是 token，视频也是 token。
