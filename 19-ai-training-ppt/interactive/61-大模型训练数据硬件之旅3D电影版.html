术语表

HBM (High Bandwidth Memory)
高带宽内存
3D 堆叠 DRAM，GPU 主显存。H100 配备 80GB HBM3，带宽 3.35 TB/s。
SRAM (Static RAM)
静态随机存储
GPU 片上缓存，速度极快（~19 TB/s）但仅 KB 级容量。
SM (Streaming Multiprocessor)
流多处理器
GPU 基本计算单元。H100 有 80 个 SM，每个含 128 CUDA Core + 4 Tensor Core。
Tensor Core
张量核心
专用 4×4 矩阵乘加单元。每周期 64 次 FMA 运算，AI 训练核心引擎。
CUDA Core
通用计算核心
GPU 通用并行计算核心，处理标量和向量运算。
Warp
线程束
32 个线程同步执行的最小调度单位，SIMT 模型的基础。
NVLink
高速互联总线
NVIDIA GPU 间高速通信总线。H100 双向 900 GB/s，比 PCIe 快 14 倍。
NVSwitch
互联交换机
GPU 互联交换芯片，实现多 GPU 全互联拓扑。
PCIe (PCI Express)
标准总线
CPU 与 GPU 之间的标准通信总线。Gen5 x16 带宽 64 GB/s。
TSV (Through-Silicon Via)
硅通孔
HBM 层间垂直互联技术，直径仅 5-10μm，实现 3D 堆叠高带宽。
AllReduce
全局归约
分布式训练中梯度聚合操作。先 ReduceScatter 再 AllGather。
FlashAttention
闪存注意力
利用 SRAM 分块计算注意力，减少 10-20× HBM 访问，速度提升 2-4×。
Mixed Precision
混合精度训练
FP16 计算 + FP32 存储。节省 ~50% 显存，Tensor Core 原生加速。
Gradient Checkpointing
梯度检查点
不保存部分激活值，反向时重算。节省 ~60% 激活内存，多 ~33% 计算。
Forward Pass
前向传播
输入数据逐层计算得到预测结果的过程。
Backward Pass
反向传播
从损失函数反向计算各层参数梯度，用于更新权重。
